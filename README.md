# Ecommerce-order-management-dbms
DBMS Capstone Project – E-Commerce Order Management System 

## Project Description

The E-Commerce Order Management System is a DBMS project developed using PostgreSQL. It manages customers, products, orders, order items, payments, and shipments using a relational database.

The project demonstrates database design, ER modeling, SQL implementation, CRUD operations, joins, subqueries, constraints, testing, and data validation.

## Technologies Used

- PostgreSQL
- SQL
- GitHub

## Main Modules

- Customer Management
- Product Management
- Order Management
- Order Item Management
- Payment Management
- Shipment Management

## Database Tables

1. CUSTOMER
2. PRODUCT
3. ORDERS
4. ORDER_ITEM
5. PAYMENT
6. SHIPMENT
